# Нора — журнал работы и решений

Здесь собрано всё, о чём мы договорились, что сделано и что осталось. Код приложения и сайта — в этом же репозитории (`app.html`, `tools/`, `site.css`). Макеты — в папке `mockups/`.

Последнее обновление: 13 ноября 2026.

## Что такое Нора
- Telegram-бот **@Wonderbookworld_bot** + мини-приложение `app.html` + сайт с подборками и страницами книг (moya-nora.github.io).
- Главная ценность — **персональные рекомендации под вкус человека** (а не «все книги в одном месте»).
- Канал: **@nora_bookworld** («Книжная нора»), ведёт Шуршуня.
- Домен куплен: **nora-books.ru** (sweb.ru). DNS настроен на GitHub Pages; переезд включится сам (`.github/workflows/domain.yml`), как только реестр .ru начнёт отдавать домен.

## Договорённости и вкус владелицы
- Тексты короткие, живые, без «ИИ-шного» пафоса; смотреть, как пишут живые каналы.
- Никаких «бесплатно» как главного аргумента; отдельной страницы «О приложении» не нужно — вместо неё всплывающее окно.
- Не использовать стандартные шрифты; без верхней плашки на сайте; на главной 4 подборки, только обложки.
- На страницах книг без тегов-капсул, «Признание» и жёлтых подписей; оценки и отзывы — простым подчёркнутым текстом, отзывы — на отдельной узкой странице со стрелкой назад.
- Раздел «удалить аккаунт» не нужен. Поддержка — через бота, не через личную почту.
- Токен бота не пересылать в чат (он в секрете GitHub `BOT_TOKEN`).
