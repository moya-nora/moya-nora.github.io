# Правила подборок Норы

Цель: в подборке не должно быть книги, которая удивит человека («почему это тут?»).
Правила проверяются автоматически при каждой сборке сайта (`tools/build_seo.py`, блок «ПРАВИЛА ПОДБОРОК»).
Что убрано и почему - в `tools/coll_rules_report.txt`.

## Для всех подборок
1. Нет книг, которых нет в продаже в России (`tools/ban.py`).
2. Нет ЛГБТ-книг (`books/curate.json`, список `lgbt`).
3. Нет самиздата.
4. Только книги с описанием.

## Возраст
5. Книги 18+ (`books/curate.json`, список `adult`) - только во «взрослых» подборках. Не попадают в: детские, young adult, подростку, маме, коллеге, «всем на Новый год», новогодние и зимние, уютные, смешные, трогательные, на один вечер.
6. Детские книги - только в детских, young adult, подростку, зимних, новогодних, уютных и подборках по странам.

## Жанр
7. Нон-фикшн - только в «Нон-фикшн», «Книгах, которые заставляют задуматься», «С премиями», «В тренде» и подарочных разделах (мужчине, коллеге, всем на Новый год). В подборках по странам и по настроению - только художественные книги.

## Настроение - чего не может быть в подборке
| Подборка | Не берём книги с меткой |
|---|---|
| Уютные | мрачное, жутковатое, хоррор, антиутопия, постапокалипсис |
| Книги с запахом мандаринов | мрачное, жутковатое, хоррор, антиутопия, постапокалипсис |
| Смешные | мрачное, жутковатое, хоррор, грустное, антиутопия, постапокалипсис |
| На один вечер | мрачное, хоррор (и война, поэзия - как раньше) |
| Трогательные | хоррор, жутковатое |
| Страшные | тёплое |
| Ромэнтези | хоррор |
| Любовные романы | хоррор, жутковатое |
| Young adult | хоррор |
| Детские | хоррор, мрачное |

Подборки, собранные руками (новогодние каникулы, зимние вечера, подарки, «В тренде»), по настроению не проверяются - только по пунктам 1-7.

## Как менять
Правило - строка в `MOOD_NO`, `KIDS_OK`, `NF_OK` или `SAFE` в `tools/build_seo.py`. После правки - пересобрать сайт и посмотреть `tools/coll_rules_report.txt`.
