# Нора — база знаний проекта

Обновлено: 13 ноября 2026. Дублируется в репозитории: `moya-nora/moya-nora.github.io` → `notes/`.

## 1. Что это за продукт
- **Нора** («Моя Нора», «Книжная нора») — книжный советник. Главная ценность — персональные рекомендации под вкус конкретного человека.
- Части:
  - Telegram-бот **@Wonderbookworld_bot** — открывает мини-приложение, пересылает владелице сообщения пользователей, раз в неделю шлёт подборки.
  - Мини-приложение — один файл `app.html` (работает в Telegram, в браузере и как иконка на экране «Домой»).
  - Сайт **moya-nora.github.io** — подборки, страницы книг, «Похожие на…», поиск, всплывающее окно с приглашением в приложение.
  - Канал **@nora_bookworld** («Книжная нора»), ведёт персонаж Шуршуня.
- Домен куплен: **nora-books.ru** (регистратор sweb.ru, аккаунт hirebitru). DNS: A @ → 185.199.108–111.153, CNAME www → moya-nora.github.io. Переезд включится автоматически, когда реестр .ru начнёт отдавать домен.

## 2. Возможности приложения
- Экраны: **Нора** (главная: «Шуршуня советует», «Новое от твоих авторов», полки «Хочу прочитать» / «Прочитано»), **Лента** (свайпы книг под вкус), **Поиск**, **Друзья**, **Статистика**.
- Регистрация по почте (Firebase Auth), письма на русском. В Telegram — синхронизация через CloudStorage.
- «Шуршуня советует» — случайный набор из ~70 книг, лучше всего подходящих к полкам; без полок — случайные известные книги.
- Поиск: по названию/автору (нечёткий), фильтры (жанр, настроение, тропы), **поиск по описанию** («про Южную Корею», «когда грустно», «страшное на ночь», «на один вечер») — без ИИ, по тегам, странам и аннотациям.
- Карточка книги: описание, факты, «Где прочитать?» (онлайн: ЛитРес, Яндекс Книги, Ozon, Wildberries; офлайн: книжные рядом, Читай-город, Буквоед), отзывы Фантлаба.
- Статистика: цель на год, месяц, достижения, вкус, челлендж месяца.
- Друзья: приглашение по ссылке, видно, что читают друзья.
- Обложки: Фантлаб (только при совпадении автора), ЛитРес, ИИ-обложки (ночная генерация), иначе рисованная.

## 3. Каталог книг
- Базовый каталог в `app.html` (~2300 книг с тегами, аннотациями, фактами) + `books/books.json` + новинки `books/new.json` + ЛитРес `books/litres.json` (в т. ч. самиздат, полные аннотации) + настроения из отзывов `books/tags.json`. Всего ~100 000 книг.
- Теги настроений и тем: грустное, атмосферное, любовь, юмор, уют, тёплое, светлое, мрачное, война, магия, драконы, ромэнтези и др.; тропы для ромэнтези (от врагов к возлюбленным, академия магии…).

## 4. Техническое устройство
- Хостинг: GitHub Pages (репозиторий `moya-nora/moya-nora.github.io`).
- Сайт генерирует `tools/build_seo.py` (страницы `/k/` книг, `/c/` подборок, `/p/` «похожие на», `/r/` отзывы, sitemap, JSON-LD). Стили `site.css`, свои шрифты (Onest, Cormorant).
- Firebase проект `nora-ed429` (владелец — kurdina.stanislava@gmail.com): Auth + Firestore (vaults, users, profiles, lookup, requests, notify).
- GitHub Actions: bot.yml (бот), bot_weekly.yml (воскресные подборки), new.yml (новинки), books.yml, enrich.yml, covers.yml, aicovers.yml (ИИ-обложки ночью), litres.yml (раз в месяц), indexnow.yml (поисковики), preview.yml, channel.yml (посты в канал), domain.yml (автопереезд на nora-books.ru), probe.yml (проверки).
- Секреты GitHub: `BOT_TOKEN` (есть), `BOT_FB_PASS` (нужно добавить для новостей по желанию).
- Внешние источники: Фантлаб API, ЛитРес API, Pollinations (картинки).

## 5. Решения и вкус владелицы
- Коротко, живо, без «ИИ-шного» пафоса; смотреть, как пишут живые каналы.
- Не делать акцент на «бесплатно»; без отдельной страницы «О приложении» — всплывающее окно.
- Не использовать стандартные шрифты; на сайте без верхней плашки; на главной сайта 4 подборки, только обложки.
- На страницах книг без тегов-капсул и «Признания»; оценки и отзывы — подчёркнутым текстом; отзывы на отдельной узкой странице со стрелкой назад.
- Раздел «удалить аккаунт» не нужен. Вопросы — в бота, не на личную почту.
- Токен бота не пересылать в чат.
