# Нора

Telegram Mini App: прочитанное по странам, векам и авторам, «Хочу прочитать» и Тевосгинк.

Адрес: https://moya-nora.github.io · бот: https://t.me/Wonderbookworld_bot

## Каталог книг

- Ручной каталог с описаниями и тегами — `CAT` внутри `app.html` (≈2,3 тыс. книг).
- Большой каталог — `books/books.json` (≈105 тыс. книг из Викиданных: все литературные произведения и книги со статьёй в Википедии). Собирается `tools/build_books.py`, задача GitHub Actions «Книжный каталог» (`.github/workflows/books.yml`) — 2-го числа каждого месяца, вручную и при изменении сборщика. Журнал последней сборки — `books/build.log`.
- Приложение подгружает большой каталог после запуска; подборки Шуршуни, фильтры, лента и поиск работают по обоим. Описания и обложки для книг большого каталога подтягиваются при открытии (Фантлаб, иначе русская Википедия).
